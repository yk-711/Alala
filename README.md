# متجر سطول — النسخة المصححة

تم إصلاح وتجهيز النسخة وفق المطلوب:
- حذف الشريط العلوي الذي يحتوي رقم الهاتف والبريد وروابط التواصل.
- تحويل الهوية البصرية إلى الأسود والأبيض والذهبي، مع إزالة الألوان الحمراء والخضراء من التصميم.
- استخدام `assets/login-background.jpg` كخلفية رئيسية للموقع وصفحات الدخول.
- استبدال جميع مسارات `/manus-storage/` المفقودة بروابط صور عبايات خارجية.
- إزالة اعتماد تسجيل الدخول على رابط Supabase الخاطئ؛ تسجيل الدخول والتسجيل أصبحا يستخدمان `/api/auth/...` من نفس الخادم.
- إضافة `account.html` حتى لا يفشل التحويل بعد تسجيل الدخول.
- إصلاح استعادة كلمة المرور محلياً عبر رمز آمن صالح 30 دقيقة، مع دعم إرسال البريد عبر Resend عند ضبط `RESEND_API_KEY` و`MAIL_FROM`.
- إعادة تفعيل تسجيل الدخول عبر Google بشكل حقيقي عبر OAuth 2.0 من الخادم.
- إصلاح مسار fallback المتوافق مع Express 5.
- إضافة `pgcrypto` إلى قاعدة البيانات.
- حذف ملف `.env` الذي كان يحتوي إعدادات/أسراراً فعلية من حزمة المشروع؛ استخدم `.env.example`.

## تشغيل
1. أنشئ PostgreSQL ونفّذ `backend/schema.sql`.
2. انسخ `backend/.env.example` إلى `backend/.env` وضع القيم الحقيقية.
3. من مجلد `backend` شغّل `npm install` ثم `npm start`.
4. افتح عنوان الخادم.

ملاحظة: روابط صور العبايات الخارجية تعتمد على اتصال الإنترنت أثناء تحميل الصور.
